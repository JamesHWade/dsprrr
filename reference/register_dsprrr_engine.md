# Register dsprrr Engine with parsnip

Registers the dsprrr engine for use with llm_predict model
specifications. This function is called automatically when the package
loads if parsnip is available.

## Usage

``` r
register_dsprrr_engine()
```

## Value

NULL (invisibly), called for side effects.

## Examples

``` r
if (FALSE) { # \dontrun{
register_dsprrr_engine()
} # }
```
