# Reasoning effort parameter for dials

`reasoning_effort()` creates a dials parameter for the reasoning effort
of reasoning models such as gpt-6-luna, with the values `"low"`,
`"medium"` and `"high"`. Use it instead of
[`temperature()`](https://jameshwade.github.io/dsprrr/reference/temperature.md)
when tuning a reasoning model.

## Usage

``` r
reasoning_effort()
```

## Value

A dials qualitative parameter.
