# Reasoning Effort Parameter for dials

Creates a dials parameter object for reasoning model effort level. Used
with reasoning models like OpenAI o1/o3/o4-mini and GPT-5.

## Usage

``` r
reasoning_effort()
```

## Value

A dials qualitative parameter object.

## Examples

``` r
if (FALSE) { # \dontrun{
reasoning_effort()
} # }
```
