# Clear Module Traces

Clear all recorded traces from a module while preserving other state.

## Usage

``` r
clear_traces(module)
```

## Arguments

- module:

  A DSPrrr module

## Value

The module (invisibly) with traces cleared

## Examples

``` r
if (FALSE) { # \dontrun{
# Clear traces after analysis
my_module <- clear_traces(my_module)
} # }
```
