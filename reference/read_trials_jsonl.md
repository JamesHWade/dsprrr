# Read Trials from JSONL File

Read Trial objects from a JSONL file.

## Usage

``` r
read_trials_jsonl(path)
```

## Arguments

- path:

  File path to the JSONL file.

## Value

A list of Trial objects.

## Examples

``` r
if (FALSE) { # \dontrun{
trials <- read_trials_jsonl("trials.jsonl")
} # }
```
