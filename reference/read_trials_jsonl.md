# Read Trials from JSONL File

Read optimization trial records from a JSONL file.

## Usage

``` r
read_trials_jsonl(path)
```

## Arguments

- path:

  File path for the JSONL file.

## Value

A list of optimization trial records.

## Examples

``` r
if (FALSE) { # \dontrun{
trials <- read_trials_jsonl("trials.jsonl")
} # }
```
